# Survival Survivors

**Survival Survivors** is an upcoming isometric roguelite that blends fast-paced survival combat, exploration, base building, and tower defense into a single gameplay loop.

Every expedition is a gamble.

Push deeper into the unknown to gather resources, uncover secrets, and grow stronger, but don't stay away for too long. The longer you're gone, the greater the threat to your World Tree.

> *How far are you willing to explore before you have to run home and defend your World Tree?*

⚠️ **Early prototype** — Everything is subject to change as the game evolves.
